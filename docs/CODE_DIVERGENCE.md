## 为什么这件事值得单独记

`metadata.json` 里有 `code.run_matrix.py` / `code.session_runner` 的哈希，
**我们一直用它们判断"两条 run 是不是同一代 harness"**。
如果仓库里的代码和跑过的不一致，**哈希比对就失去意义**——
你无法从仓库重建出当时到底跑了什么。

**投稿前必须让这两者一致，否则"可复现"这句话是空的。**
