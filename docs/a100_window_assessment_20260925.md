# lab-A100：方向 D（第二配置复现）为什么仍然跑不了（2026-09-25 00:2x）

这一页把「为什么跑不了」写实，替掉此前那句含糊的「util 长期 49–100%，整晚没窗口」。

## 一、旧判据是错的 —— 它给了假阳性

`/data/xbw/a100_watch2.sh` 每 30 分钟采一次**瞬时**利用率，判据是
「空闲显存 >60GB 且 util <20%」。它的日志显示：

```
09-24 21:44 gpu0=4553MiB/1%/free75G gpu1=9074MiB/63%/free71G gpu2=78064MiB/73%/free3G  free=1 big=1
09-24 22:14 ... big=1
09-24 22:44 ... big=1
09-24 23:14 ... big=1
09-24 23:44 ... big=1
09-25 00:14 ... big=1
```

**连续六次报「BIG WINDOW」**。但同一分钟按进程查，这台机器上有**三个租户在跑活跃训练**：

| 属主 | 进程 | 已跑时长 |
|---|---|---|
| `yz` | `python -m CE3_baselines.main`（三个进程） | 3 分 23 秒 / 14 分 / 7 分 —— **刚起的** |
| `qcrs` | `vllm-qwen-cu121` | 1 天 13 小时 |
| `linchen` | `run_experiment.py --dataset beta` | 14 小时 |

我按 12 秒一次连采一分钟，gpu0 的 util 在 **0 / 0 / 1 / 40 / 62** 之间跳。
瞬时利用率在「一个 kernel 刚结束、下一个还没提交」的瞬间就是 0 ——
**旧判据测的是瞬时值，不是可用的算力。**

这是本项目在 3090 上栽过的那类错误的翻版：**用错的口径判可用性**，
后果是把 run 跑进一台共享机器，而引擎侧指标事后看不出来
（见 `docs/finding_concurrency_contamination_20260924.md`）。

## 二、新判据（`a100_window.sh`，已挂上）

四条同时满足、且要**持续 10 分钟**：

1. 每 20 秒采样，看窗口内的 util；
2. 最大空闲显存 > 60GB；
3. 该卡上**别人的**计算进程占用 < 1GB —— 有人挂着 4GB 就是有人在用；
4. 连续 ≥10 分钟满足。

细则：`foreign` 必须**按卡**统计，不能全机合计（第一版写成全机合计，
GPU2 被占 80GB 会把 GPU0 的窗口一起算掉 —— 写的时候就犯了，已在脚本注释里记下）。

装好后的前两次读数：

```
09-25 00:19:24 free=75G util=65% foreign=4466MiB streak=0/30
09-25 00:19:44 free=75G util=25% foreign=4466MiB streak=0/30
```

**GPU0 上有别人的 4.4GB 常驻**，util 在 25~65% 之间。不是窗口。

窗口出现时脚本会写 `/data/xbw/a100_window_open`（**不自动起实验** ——
起一个多小时的长跑是不可逆动作，要人看过再定）。本地已挂一个监控盯这个标记文件。

## 三、就算有窗口，还缺什么

即使窗口出现，方向 D 目前**还缺一个可比的设计**：

- **模型不同**：A100 上 `/data/models` 有 `Qwen2.5-7B-Instruct`，
  但**没有** `Qwen2.5-Coder-7B-Instruct`、也没有 YaRN 变体。
  论文主配置是 coder + YaRN×3（96K 上下文）。用 7B-Instruct 跑，
  上下文只有 32K，prompt 结构与前缀复用都会变。
- **同时变的轴太多**：换卡（24GB→80GB）、换模型（coder→instruct）、
  换上下文（96K→32K）、换池子（101,432 → 约 9 倍）。四条轴一起动，
  测出来的是「一个完全不同的配置」，不是「同一个配置换硬件」。
- **真正需要的那条对照在 3090 上**：论文因果主张最缺的是
  「同卡、同 trace、只改池子大小」，那个已经预注册
  （`docs/prereg_halfpool_20260924.md`）并在 3090 队列里。

**结论**：方向 D 仍然交白卷，但理由现在是具体的三条（没有真窗口 / 模型不可比 /
同时变的轴太多），而不是一句「util 高」。**宁可交白卷，也不产出不可比的数据。**
若窗口真出现，先要做的不是起跑，而是**先把设计写死**（哪条 trace、哪个模型、
池子取多少、与论文哪一条主张对照）。
