## 二、改掉的（10 条）

### 2.1 **`\footnote` 被 Python 转义吃成了换页符**（最严重，codex 抓）

`sec_discussion.tex` 里出现 **U+000C + `ootnote`** —— 我在 Python 里写
`"\footnote"`（**单**反斜杠，`\f` 是换页转义）造成的。PDF 里它成了正文文字
「**ootnoteFor F:t85**」，脚注变成了正文句子。

**而 `Float too large` / `Overfull` 两条排版守卫都看不见它** —— 它不是排版问题，
是**源码里多了一个控制字符**。已修，并加守卫：**全稿扫控制字符**
（反向测试：塞一个换页符 → MISS，并指出 `文件:位置(0xXX)`）。

### 2.2 **A100 的 Δ 只差 0.6 秒就会翻转判决**（子 agent 抓，我修的过程中当场撞上）

`gen_a100_delta.py` 从 `a100.csv` 的 **1 位小数**列建包络并插值，
而 3090 那条管线 2026-09-24 已经专门改成 6 位全精度（`frontier.py` 的注释记的就是那次事故）。
**A100 这边同一个 bug 一直活着。**

全精度：`cap16 = 88.3372173` 分，控制器 = `88.3472761` 分 ——
**控制器慢 0.6 秒**，刚好还落在锚点右边 ⇒ Δ = +0.099975 ⇒ **ON（打平）**。
若控制器快 0.6 秒，`piecewise` 返回 `None` ⇒ 判决变成 **LEFT-OF-FRONT**。

我改精确度时**当场翻了一次**：先把锚点改成全精度、臂还是 1 位，于是 88.3 < 88.3372
→ 判决翻成 LEFT-OF-FRONT。**锚点与臂必须同精度** —— 现在两边都从 `steps.jsonl` 现算。

⚠ 正文那句「the same wall clock as the controller, to the tenth of a minute」
按字面成立（都印 88.3），但它读起来像「两条一样快」，实际是「**控制器慢 0.6 秒、
刚好在锚点右侧**」。已在 §A100 写明这个方向。
