## 0. 先定一件事：不追整批 3–4x

```
步时间 = D(解码) + P(上下文 prefill)
3090 / 7B / 40–65K 上下文：D 占大头
⇒ 整批 makespan 上界 ≈ (D+P(60K))/(D+P(增量)) ≈ 1.4–2.4x
§11.6 的「零空闲 + 零重算」绝对上界也只有 2.75x
```

Concur 的 4.09x 是 16×H100 / 大 batch / 另一模型的口径，与单卡 3090+7B 不可比。
**能上「倍数」的是另外三个口径**（下面选一个做主 headline，其余做支撑）。

## 2. 决定成败的对照（目前缺的）

### ★★★ 2.1 静态 cap 基线（生死实验）
在同一 long19 / atonce trace 上跑 `cap1 / cap2 / cap3`（+HiCache）。**没有它，整篇立不住**：
- 审稿人第一问：「你的收益是不是只是加了一个固定的并发上限？」
- RTAS 那篇已经证明静态 cap 在泊松负载下极强；如果 atonce 负载下 cap2 也拿到大部分收益，
  主线必须改成「非逐负载调参 + tier 感知」，而不是「我们比无控制快 N 倍」。
- 这也正是师兄说的「实验报告」问题的解药：**有对照组，才叫结论；没有，只是现象。**

### 2.2 干净重复（n=2）
default / foyer，hc2，long19。10 月的读数大多 n=1 且带 revoke bug / permit bug / 热降频。

### 2.3 tier-aware 准入（机制创新，把 hc8 反转变成贡献）
用已修好的 device/host 命中分解做「按 KV 所在层级定价」的准入：
- 假设：驱逐到 host ≠ 真丢；复活代价 = 搬运成本 vs 重算成本；
- 预测：**hc8 上从 0.89× 恢复到 >1.1×，hc2 不退**；
- 这是唯一能让 hc8 那条「我们更慢」从威胁变成发现的东西。

### 2.4 其余
- `nohc` 消融对（HiCache 到底值不值）；
- 第二条 trace（mid17 / main31）一对（泛化）；
- big27 在 revoke bug 修复后干净重跑（n=1 为止）。

## 4. 预注册判据（跑前写死，三种结果都写处置）

```
主 headline（A 方案）成立的判据：
  (i)  miss rate 至少改善 5×（保守；现有单次读数 43×）；
  (ii) 最佳静态 cap 的 miss rate 比我们差至少 2×（否则「cap 就够了」）；
  (iii) 单会话端到端中位不劣于 1.2×、且 p90 不劣化超过 20%。
若 (iii) 不过：照实写成「快在整批/达标率，不在尾部」，不许藏。
```

**三种情形**（跑之前写）：

1. cap 明显输：主线 = 「容量核算准入 + tier 定价」的机制论文，数字用 A 方案；
2. cap 打平：主线 = 「无需逐负载调参 + tier 感知」，headline 换成
   「同一达标率下少调 3 个参数 / 跨 hc2-hc8 不退化」；
3. cap 赢：**如实写，并把论文降级为 system paper 的一个 section** —— 不许改判据。

## 8. 从 RTAS 模拟审稿学到的硬约束（2026-10-22，详见 `docs/rtas_review_notes_20261022.md`）

两路模拟审稿（weak reject / reject）在四点重合，全部适用于第二篇：

1. **统计**：点估计落进带内 ≠ 没有改善。每配置 n≥2 + CI/配对 bootstrap；预注册 margin
   并做等价性检验与功效分析。第二篇的 headline（miss rate 43×）必须带 CI。
2. **基线必须实测**：不用插值前沿；静态 cap 要真跑，最好是「在别的 trace 上调好的 cap」。
3. **记录 clock/temp/power**：τ 随并发上升必须排除热降频——这正是我们 10 月踩过的坑
   （GPU 2/3 降到 210MHz）。每条 run 存 `nvidia-smi` 时间序列。
4. **时钟口径**：engine 与 ready 双钟同权；session 级 deadline 要有语义依据。
5. **不能“半空转”**：⚠ **十月线已经露出这个把柄** —— foyer 引擎空转 56.7 min
   vs 无控制 26.1 min（DECISION_BRIEF）。审稿人会说「你的收益来自把活排在门外，
   引擎利用率反而更低」。第二篇必须在计划里加一条：**报预算利用率/引擎空转，
   并证明空转买到的前缀驻留 > 空转的代价**；否则这个负数会盖过 1.43×。
6. **范围写进摘要**：单卡/单 trace/单 SLO 不写成一般结论。
