## 这一批改了什么（**逐条都要核**）

### A. 绝对路径守卫：又补了三条漏（两条线各报一条，我自己测出一条）
1. **写调用跨物理行**（中立复核）：闭包那一支的最终判定原为**逐物理行**，且更深一层 ——
   `tokenize` 在**括号不闭合的行片段**上抛 `TokenError`，而 `_toks` 吞掉异常 ⇒ `_names()` 空。
   ⇒ 改成用**逻辑行（括号块）**窗口。
2. **纯别名**（codex）：`PAPER='/root/…'; X=PAPER; open(X,'w')` 漏 —— 我收窄 `_pathy` 时
   把别名一起挡了。⇒ `X = <闭包名>` 也沿闭包传。
3. **嵌套 + 跨行**（我自己测出）：写标记原为 `open\s*\([^)]*["'][wax+]`，`[^)]*` **过不了嵌套括号**
   （`open(os.path.join(OUT,'x'),` 里的 `)` 会截断）。⇒ 改成**语句级** `_is_write(blk)`。
4. `_pathy` 也认裸 `join(`（`from os.path import join`，codex §12.2）。

### B. 数词守卫（codex 第 12 项②）
5. 「那个副本下四条 run 全被标记」原来只核**数据**，没绑**正文数词** ⇒ 改成 `num_words(现算值)`。

### C. 检查数下界
6. `_CHECKS_FLOOR` 871 → **876**（中立复核实测下界比实测低 5，本批 F1 块正好约 5 条）。

### D. 交付件
7. 流程改成 **打包 → 立刻 tar → 验证在解包副本里做**（原来在交付目录里跑验证命令，
   Python 生成的 11 个 `.pyc` 进了 tar）。实测新 tar 里 `.pyc` **0**。

### E. **正文改动**：补充材料指向 12 处 → 1 处
8. 依据：独立 agent 逐篇扫 22 篇 RTAS 2026（真论文 20 篇）—— **没有任何一篇达到 ≥5 次指向**，
   最多 4 次；主流是「一行代码链接」。**9 处直接删句**、**2 处改成只说事实 / 只指 `attribution.csv`**、
   唯一保留的一处在 §VI Reproducibility，写成总指向并明说 no verdict depends on it。
9. ⚠ 改写时我自己踩了一个坑：那句一开始写成 markdown 的 `**…**` ⇒ LaTeX 里会**原样印星号**
   （本项目在补充材料上犯过一次）。已改 `\emph{}`，`pdftotext` 复核星号 **0**。
