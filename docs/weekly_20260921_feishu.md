# 26-09-21周报

这周的主线：**把「我们的方法是对的」这件事，从"讲得通"变成"验得了"。**

## 现在在做什么

给显存受限的 GPU 上的 agentic 服务做**会话级准入控制**——在请求进推理引擎之前决定放行还是排队。

和上周相比，这周的落点从"机制怎么做"移到了"怎么证明它是对的"。原因是上周那三个机制在文献里都能找到对应工作（容量核算准入、状态保留式挂起、等待-代价比排序），**机制本身不新**；真正可能站得住的是我们围绕它测出来的东西。

## 走过的技术路线

**路线一：容量核算准入。** 准入时刻显式核算「池子容量 / 在场会话占用 + 预测增长 / 新到会话体量」，用命名许可保证准入计划与执行一致。

$$Admit(s) \iff m\left[\sum_{i \in \mathcal{A}}\left(x_i + \hat{g}_i\right) + \left(x_s + \hat{g}_s\right)\right] \le \rho C_{\mathrm{pool}}$$

**路线二：分层缓存的状态保留式挂起。** 需要腾空间时把会话 KV 从显存挪到主机层，L1 立即释放、历史保留；复活时只需搬回，不必重算。实测**搬运 0.005 ms/token 对重算 1.08 ms/token**，差两个数量级。

**路线三：等待-代价比的复活排序。** 被挂起的会话不按 FIFO 回归，按 $W/T$ 排序，等待越久、复活代价越小的越先回来。

**这三条这周得出的结论是：都能跑，但不能当"新颖性"写。** 所以这周的力气花在把它们背后的**证据**做扎实：

- 建立**断言台账**——论文里每条结论登记证据来源与状态，只允许四种：实测可复现 / 推论 / 待核 / 已撤回。正文引用时状态必须一致。
- 控制器里"凭估计"的量，尽量换成**引擎自己的测量**。这周新落地的是**五类资源的同刻测量**：同一时刻、同一会话集合上分别读「逻辑上下文之和 / 引擎锁定的 KV / 可回收部分 / 主机层占用 / 已承诺未物化的预留」。此前控制器每一拍都从引擎端点取回全部指标，却只读走一个、其余丢弃；现在全部记入决策日志，**每拍自动累积，不额外占卡时**。

## 目前的状态

同一批 run、两条口径，赢家不同：

- **对缓存命中率**：`cap4 + HiCache` 在最左上。
- **对 SLO**：同一个点掉到左下，`Foyer + HiCache` 在最上。

**门槛是选的不是测的。** 取 SLO ≥ 85% 时我们的 `Foyer + HiCache` 领先 `cap2` **4.3%**；取 60% 时 `cap4 + HiCache` 领先 **26%**。

这周新出的点是 `cap4 + HiCache`：它同时拿到 **219 分钟**和 **68.1% 命中率**，而 `cap4` 是快但丢缓存（45.9%）、`cap2` 是保缓存但慢（310.5 分钟）。**分层缓存把"保缓存 vs 提并发"这个取舍本身消掉了**——而且它是个静态配置，没有控制器。

| 策略 | 墙钟(min) | 命中率 | SLO% | TTFT p50 |
|---|---|---|---|---|
| cap4 + HiCache | 219.0 | 68.1% | 63.4% | 5473 ms |
| cap4 | 257.6 | 45.9% | 55.7% | 7215 ms |
| Foyer + HiCache | 297.6 | 69.7% | 89.8% | 2228 ms |
| cap2 | 310.5 | 67.7% | 89.5% | 2183 ms |

**性能主张目前没有干净的证据。** 最好的同 SLO 比较是 `Foyer+HiCache` 对 `cap2`：297.6 对 310.5 分钟、SLO 89.8% 对 89.5%，快 4.3%——与跨天不可归因的量级同阶，不足以作结论。能干净回答它的只有**配对实验**（两臂并发、同机器同条件），协议已定。

另外，这周核验掉两处写进过论文、但站不住的结论：

- **「三个并发会话需要 117% 池子，所以必须超订」**——那是**五个**会话的数，四个是 91.4%，装得下。
- **`cap3_r2` 实测跑的是 cap4**——`cap` 字段 200 条全是 3，但 195/200 次准入发生在 `active=3` 时，落地后 4 个在飞。已作废重跑。

## 之后怎么做

1. **定口径**：性能主张 / 测量主张，二选一——因为上面那个门槛问题。
2. **`cap3_fixed` / `rl90fix` 验收**：判据是事件重建 `max active ≤ 3` 与记账不变量，不是看墙钟。
3. **五类资源数据累积**：下一个控制器路线的 run 起自动记录。
