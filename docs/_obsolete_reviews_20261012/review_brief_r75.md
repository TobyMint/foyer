## 这一批改了什么（**逐条都要核**）

**背景**：r74 中立复核发现，检查器里切「逻辑行（括号块）」的那段代码**也在用正则近似词法**
（`re.sub(r'"[^"]*"|\'[^\']*\'', …)`）—— 三引号里一个孤立的 `(` 就能让块从字符串中间开始，
使 `tokenize` 失败、`_names()` 返回空集，**闭包支对该块完全失明**。可复现漏报。

1. **块切分改用词法器**：整个文件 `_blank()` 挖一次（跨行字符串才挖得对），再**按行号**取回。
   用 `split("\n")` 而**不是** `splitlines()`（要与 `_blank` 的行计数对齐）。
2. **`_blank()` 返回 `(文本, 是否挖空成功)`**；`_open_has_mode` 在失败时**返回 True**（报）。
3. **`_toks()` 失败返回 `None`**（原来返回 `[]`，使「词法化失败」与「这段没有名字」不可区分）；
   `_names()` 同样。三个调用点各自回落，且**分别有界**：
   - `_pathy()`：失败 ⇒ 有界**文本**判据（`join(` / `os.sep` / `pathlib` / 引号串里含 `/`）；
   - 闭包增长：失败 ⇒ 对闭包名做**词边界**匹配；
   - 闭包支命中：失败 ⇒ 对该名字做**词边界**匹配。
4. **新增一条时间戳卫兵**（`_CHECKS_N` 881 → **882**）：`.labels.json` 与 `.counts.json`
   **都要不比 `paper/figs/` 下任何一张 PDF 旧**（原来只有 `.labels.json` 跟图 2 比）。
5. 标签守卫**明示作用域**（只查重名，不查内容）＋ 删掉注释里会过期的「现在 = 878」。
