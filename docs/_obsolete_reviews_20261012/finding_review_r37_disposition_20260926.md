独立复核实测（改前）：`has("40 runs", 4)=True`、`has("6.5 ms", 6)=True`、

**被新的右边界挡住了**。14 个边界用例逐条验过（含 `{,}` 千分位、`1999 of 999`）。

## 二·补、codex r37（另一条线）报的四条，逐条处置

1. **§VII 的守卫只查「两个数都在附近」，不查归属** —— 把「117 sessions, 390 rounds」
   **对调**、或把「18{,}809 against 23{,}187」对调，**都不报 MISS**。同属
   「两个数各查各的，换位仍通过」那一族。已把这两处改成查**整句**；
   两个对调构造的反向测试都报 MISS ✓。
   （它同时说「给任一数字添末位 0 也会通过」——**实测不成立**：
   `has("188090", 18809)` 为 False，右边界挡住了。它那一测跑在我改完之前。）
2. **时点词正则漏了 TeX 的不换行空格**：`for~now` 排版出来就是 "for now"，
   而原来只认 `\s+`。已把词间分隔改成 `(?:\s|~|\\ )+`。反向测试 ✓。
   （`\emph{writing}` 这类**插标记**的写法仍不追 —— 那是排版不是措辞，
   与它自己的判断一致。）
3. **等值断言不覆盖模型**：改掉 `runner_argv` 的 `--model` 仍会通过。
   已补 `--model` / `--tokenizer` 的比较，反向测试 ✓。
4. **caption 解析还能被 `\\%`（双反斜杠后的 %）与 `\verb|%|` 绕开** ——
   前者是**故意隐藏**、后者会**截断成假 MISS**。**不追**：这是「形状匹配有极限」
   那一类（构造越来越刻意），已在此写明边界。同一类的
   `Thirty\hspace{0pt} two`（读成 2）也记在这里。
