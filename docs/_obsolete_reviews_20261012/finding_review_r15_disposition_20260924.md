## M2 本批唯一把结论改强的地方站不住（已回退）

上一批我把 §VI 的「foyer 慢 14.3%」从「落在抖动内、不算输」改成
「是重复散布（1.7%）的八倍、算墙钟上的输」。子 agent 指出：**同一节自己**在给
±10% 扰动做正当性时写的是「我们的重复对散布到 22.4%」，而本仓

用一对重复（1.7%）去推翻自己先前用全仓散布下的结论，正是「挑对自己有利的噪声尺度」。

修法：回退为 **not a loss → did not win**，并且把那个 22.4% 变成**可追的数**：
新增生成器 `gen_repeat_spread.py`（实验机跑，判据：同 policy + 同 trace + HiCache、

本文两条 trace 上的组是 1.4–6.1%）。正文改成引这张表。
▸ 顺带发现第一版生成器把中止的 run（`_timedout_591steps`）和不同代码代混进同一组，
算出 58.2% 的假散布 —— 已加「未跑完不进组」的过滤。
