## 这一批改了什么（**逐条都要核**）

### A. 绝对路径守卫：判据整块重写（r67 两条线各给了反方向的构造）
1. 删除 `_WR` 里「名字像输出」的启发式（`^\s*(OUT|DST|DEST|OUTDIR|TARGET)\s*=`）
   —— 它导致**误报**（`DST='/root/…'` + 只读 `open(DST).read()`）。
2. 闭包改成**只沿「构造路径」的赋值**传递（`os.path.join` / `os.sep` / `pathlib` /
   字符串里含 `/`），因为第一版**顺着数据流爆炸**：`m = json.load(open(mp))`
   把 `pool`/`trace`/`wall` 都染上 ⇒ `f.write("⚠ KV pool differs …")` 被当成写语境。
3. 名字与字符串一律用 **`tokenize`** 判；`_pathy` 额外认 `FSTRING_MIDDLE`
   （3.12 起 f-string 不是 STRING token）。
4. 白名单 `_ABS_OK = {"run_matrix.py"}`，理由写在代码注释里。

### B. 四个脚本的 `__file__` 推导改成**带回退**
5. 起因：r66 我改成「上溯两层」，但**实验机上的真实布局不是 `<tree>/scripts/`**
   （`agg.py` 在 `TraceLab/replay/scripts/`、三份 `smoke_*.py` 在**树根**）。
   现在：推导出来的树里**有 `results/`** 才用它，否则回退原来的绝对路径。

### C. 图新鲜度判据
6. 「拷贝树容差」的 mtime 跨度改成对**整棵树**（`paper/**` + `scripts/**`）算；
   阈值 **3600 s → 120 s**（项目自己那次真事故是 39 分钟 = 2340 s）。
7. 「有 `.deps.json` 且判为拷贝」时误打印「无 .deps.json」—— 拆成 `if _copied: pass / elif exists:`。

### D. 打包器 / 校验器
8. `pack_artifact.py` 按**目录名**排除 `__pycache__` 与 `.pyc`（原来 `skip` 比文件名 ⇒ 从未生效）。
9. `verify_manifest.py` **也忽略**字节码缓存（跑完检查器会生成 11 个 .pyc）。

### E. F1/F2：两处**此前零守卫**的断言
10. **§VI「控制器 artifact」段四条断言**（四个哈希 / 仓库那份不在其中 / 「most」是真多数 /
    「那个副本下四条 run 全被标记」）—— 补四条现算守卫。
11. **§V 归因判据句漏了代码的第三类**：代码有「步成本更高（但对照的在跑数不可比）」2 条，
    而正文写「everything else is a residual」⇒ 改写判据句，并补**第三类的条数守卫**。
12. 两条新守卫的**窗口收窄**（F1 → 15 字符、F2 → 25 字符）：`ck_near` 是**对称窗口**，
    默认 260 会让同段别处的数接住它（实测：four→five 仍被 `all four runs` 接住 ⇒ 假通过）。
