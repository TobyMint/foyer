## 这一批改了什么（**逐条都要核**）

1. **图 7 的三个标签重摆**（`cap2`/`cap3`/`cap4` 原被 `model-consistent τ₁` 红线穿过）。
   偏移改成**搜索出来的**，要求包围盒到所有线段最小间距 ≥ 1.5pt，实测 4.0 / 6.0 / 5.9 pt。
2. **新增第五类检查 `text-overlaps-line`**（文字包围盒 vs 数据线采样点）。
3. **新增第六类检查 `text-too-close-to-frame`**（下限 2pt）。起因：图 2 的 `36%`
   包围盒右缘 **575.21 > xlim 575** ⇒ **出轴 0.07pt**，而旧的 `text-bbox`
   拿「轴跨度的 0.3%」当**容差**，**看不见负余量**。
4. **`strip_cites()`** —— `paper_text()` 改成 `strip_cites(strip_comments(...))`。
   起因：`\cite{dynamo,perbank24,...}` 里的 `perbank24` 含「24」，被 `has()` 认下，
   开出一条**假通过**通道。
5. **阈值 pt/px 修复**：`_R` / `_TIP_FREE` / `_COVER` 改成按 `dpi/72` 换算，
   并断言 `figure.dpi == 200`。（原来注释写 2.5pt / 6pt，**实现的有效阈值是 0.90pt / 2.16pt**，
   静默松了 **2.78×**。）
6. **表注词数上界守卫**（上界 70，当前 44）+ 图 2 `xlim 575→585`、图 1 `ylim 104→106`。
7. **Artifact §1.6 移进主 supplement** `paper/supplement_material.md` 的 §S9
   （原来只在工作记录里），并补了 `gen_table.py` 的必需输入 `runs.csv`、
   `gen_elasticity*` 读 `arm_running.csv`、`frontier.py` 的硬编码锚点常数。
8. **文档口径改准**：「网格关掉」→「关掉满铺、留一条极淡单向」；
   红线「0 处」→「正文 0 处；`refs.bib` 注释各 1 处」。
