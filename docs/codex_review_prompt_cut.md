## 论文的核心论点（**这些不能砍**）

1. 在内存受限的 agentic LLM 负载上，**准入控制打不过调好的静态并发上限**：
   四条路线、九条变体，**零条越过插值前沿**（最好的一条在 ±1.0pp 打平带内）。
2. **为什么**：墙钟可以分解成 busy 与 idle 两部分，而在 host tier 上
   **ε（每步成本对并发的弹性）全程 < 1**，所以「加并发买到的吞吐」始终在；
   控制器**不是**输在并发变贵的地方。这是全篇的机制，也是标题的依据。
3. **同一套测量在第二张卡（A100 80GB）上**：机制复现（ε 更平），负结果**变弱**——
   如实写成「更弱的结论」，不许因为好看而调口径。
4. 方法上的贡献：**一个判据**（什么时候准入控制才可能值）+ **前沿的构造与打平带**。
