# 论文评审

## 先读再判

读 `paper/main.tex` 与全部 `sec_*.tex`，再读证据：`paper/claims_audit.md`、
`paper/data/*.csv`、`results/`（需要时）。**没读证据不下判断。**

## 评审维度

问题表述 / 动机 / 贡献清晰度 / 方法 / 假设 / 实验设计 / 基线选择 / 消融 /
统计支撑 / 可复现性 / 图表清晰度 / **主张与结果是否一致** / 局限 / 相关工作定位 / 写作。

其中「主张与结果是否一致」在本项目是重点：这是一篇负结果论文，
最容易出的问题是**把负结果说成正结果**，或者**声称解释了机制但机制没被测过**。

## 输出格式

```
## Major issues
每条：问题 → 为什么重要 → 证据（章节 / 文件 / 数字）

## Minor issues

## Questions requiring clarification
```

每条 major 必须能指到具体的节、文件或数字。**不要为了显得严格而编造弱点。**

## 必须做的事

- **标出强于证据的主张**。这是最有价值的一条。
- **预判审稿人会先攻击什么**——通常是账目与可复现性，然后才是新颖性。
- 检查是否有主张依赖已被撤回的机制（见 `CLAUDE.md` 撤回记录）。

## 不许做的事

- **不生成**虚假的审稿分数、接受概率，也不冒充某个具体会议的具体审稿人。
- 可以给「按现状投会怎样」的判断，但要说明依据，并明确这是判断不是预测。
- 不编造弱点，不编造文献。
